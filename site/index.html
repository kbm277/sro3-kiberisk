СРО 3. Киберриск

Учебный сайт, который работает внутри Docker-контейнера.

Пять контейнеров Compose

Сайт Эта страница, nginx, порт 8090.
Реестр Свой сервис на порту 8081.
Кэш и база Redis на порту 6380, PostgreSQL на порту 5433.
Мониторинг Проверка остальных четырёх сервисов.

Что такое киберриск

Актив То, что нужно защищать: данные, сервис, учётная запись.
Угроза Событие, которое может навредить активу: утечка, простой, подмена.
Оценка Вероятность × ущерб. Чем выше балл, тем раньше этот риск разбирают.

Пример реестра

Актив Угроза Вероятность Ущерб Балл
База студентов Утечка персональных данных средняя высокий высокий
Учебный портал Недоступность сервиса низкая средний средний
Почтовый ящик Фишинговое письмо высокая средний высокий
Резервная копия Копия не проверялась средняя высокий средний
Стенд из пяти образов поднимается командой docker compose up. Эта страница отдаётся контейнером site на порту 8090.
